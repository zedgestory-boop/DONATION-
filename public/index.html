Webhook Saweria

Atur URL callback di pengaturan Saweria ke URL Railway milikmu dengan path /webhook/saweria dan secret yang sama dengan variable SAWERIA_WEBHOOK_SECRET.

URL pola: https://DOMAIN-RAILWAY/webhook/saweria?secret=SECRET_KAMU. Jangan menaruh secret di README atau kode publik. Pastikan format payload dan mekanisme webhook yang tersedia di akun Saweria cocok dengan endpoint ini.
